# M2 search workbench increment

Continue approved architecture A in the existing M2 worktree. Reuse native JS,
existing session API and mobile-first CSS; no model calls or new dependencies.

Scope: metadata/keyword form with exact directory/MIME scope, live pagination,
snapshot coverage and backend warnings; fixed-version source reauthorization and
PDF page link. Use textContent, not HTML. Fence late responses when project,
filters, searches or source selection change; invalidate on file refresh/mutations
and logout. Metadata remains usable for unparsed files. No vector/hybrid claim.

3. Run bounded serial JS/HTML regression; inspect mobile layout and document
   actual verification boundaries. No database/build changes are necessary.
