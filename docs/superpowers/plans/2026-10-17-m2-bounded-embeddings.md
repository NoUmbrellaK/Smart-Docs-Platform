# Bounded Local Embedding Implementation Plan

> Execute inline in the existing isolated M2 worktree with executing-plans and TDD.
> Architecture A and routine implementation are approved; no new approval menu.

**Goal:** Encode complete existing chunks into bounded, reproducible semantic windows.

**Architecture:** One optional Python module exposes a subprocess wrapper and owns
its private child entry point. Reuse the existing worker flock. The child verifies
fixed model hashes, disables tokenizer truncation, recursively halves over-budget
character ranges, embeds one window at a time and normalizes explicitly. It does
not change chunk IDs, publish indexes, access business files or make API calls.

**Tech Stack:** Python 3.10/Linux, pinned FastEmbed 0.9.0/ONNX CPU runtime from the
verified spike; stdlib process/limits/JSON/locking. Existing parser dependencies unchanged.

**Spec:** `docs/superpowers/specs/2026-10-17-m2-document-processing-design.md`,
requirements R-01/R-02/R-03 and `docs/evidence/m2/vector-probe/README.md`.

## Global constraints

- At most 8 chunks/request, each 1–1200 Unicode characters and a unique 64-hex ID;
  nonempty/non-whitespace UTF-8 text, no forbidden C0 controls/DEL.
- Input JSON <=64 KiB; each model window <=128 tokens including special tokens;
  <=64 windows/chunk and <=128/request. Contiguous disjoint ranges cover each
  input exactly. Over-limit requests fail, never claim partial completion.
- Output <=2 MiB, fixed recipe/model revision, original chunk ID/text digest,
  relative Unicode character ranges and 384 finite L2-normalized floats/window.
- Fixed local artifact paths come only from trusted deployment configuration.
  Verify five file hashes and critical library versions. No runtime downloads,
  inherited credentials/proxy variables, network clients or text/error logging.
- Non-root; one flock across requests/processes, held until child is reaped.
  Child limits: AS 2 GiB, CPU soft 60/hard 65 seconds, output 2 MiB, no core dump;
  wall deadline <=60 seconds, kill/reap whole child process group on timeout.
  Inherited limits must not be relaxed. Existing 512 MiB parser worker unchanged.
- This is not an authorization endpoint. Only a future C++-authorized caller may
  supply business chunks; C++ publication/current-version/approval rechecks remain
  a separate increment. Offline library settings are not a network sandbox; use
  OS network isolation for the encoder deployment, as in the real tests.
- Actual heavy tests: one non-root systemd unit at a time, 1200M/1600M memory,
  no swap, 100% CPU, /dev/vda read/write 5M and 200 IOPS, <=900 seconds.
