  range返回1个片段。未启用编码器，不把hybrid请求称为实际混合检索。

  `report.items[].citations[].chunk_id` 的 `pattern` 校验失败被拒绝。
  两次拒绝分别为工具计数7、8；没有报告写入后端，也没有归档调用。

  最终预算错误不能掩盖前面的具体保存拒绝。
- 日志不保留原始工具参数，因此不知道具体无效chunk_id值、长度或来源；
  不能断言是截断、大小写或虚构，也不能将这一结果倒推为第二轮失败原因。
