之前检查已序列化请求，递归解码其中工具结果/参数的 JSON 字符串，检查两个受限夹具的
文件名、完整正文及独特标记；命中或记录失败时不调用原发送器。
不修改原始请求 bytes、供应商响应、默认 transport、重试/代理/重定向设置或产品提示词。
只记录序号、哈希、字节数、命中数和是否放行，不保存请求正文、请求头或密钥。

这不是通用敏感信息检测，也不是新增产品权限机制。`forwarded=true` 只表示放行到原 sender，
不单独证明供应商收到；本次4条观察记录与4条 model_attempt 的序号/字节数对应，
4条 model_result 均成功且有实际 usage，才共同构成这次实际调用的证据。
四次受限内容检查均0命中，未触发观察器拦截，因而本次流程没有因额外 guard 改道。
未保留原始请求，事后不能仅凭哈希重建或重新扫描其全文；这里依赖运行时观察记录。
