## 实现边界

`ReportRejection`只为既有AppError附加内部分类；原状态/码/消息保留。
路由只将报告400的分类交给FinishToolCall，后者校验固定11类、invalid_request及空来源，
SQL又限制为报告工具。分类、状态、耗时在一次UPDATE里完成；失败维持原unknown语义。
没有迁移，复用schema16的parameters JSON。没有把正文保存到日志或复制权限规则到Python。
客户端不能提交分类；正常保存不含该字段，原报告草稿与来源依赖保持既有事务行为。
只记录先遇到的拒绝类别，不记录具体哪个清单key/文本字段或实际值。
分类目前不回传模型，因此不能宣称已减少模型重试或修复H05业务失败。
