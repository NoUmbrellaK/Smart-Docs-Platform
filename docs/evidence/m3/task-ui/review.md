# 只读审查与修正

审查范围：AgentPanel、页面接线、同源API封装、静态白名单及新增测试。
独立只读审查者：m3_agent_ui_review；没有代替主流程运行浏览器验收。

首次发现：文件刷新或切换项目会执行invalidate；若它清掉busy和uncertain，
尚未返回的非幂等创建请求就可能被第二次创建绕过。首先补回归，真实失败为
create调用数2而非1，见[race-red.txt](race-red.txt)。初版回归误等候未决promise，
运行单元被主动停止；这属于测试编排错误，不作为有效业务RED。

修复：创建使用独立creating锁，生命周期清理只清视图，不释放在途请求或不明确结果。
旧视图回执不显示任务ID，提示核对任务；必须等请求结束并显式New draft才能重新创建。
回归覆盖文件刷新、项目往返、在途新草稿按钮、迟到成功和显式新草稿恢复。

二次审查结论：没有阻断发现，等待主流程真实浏览器验证。仍不保证跨标签页/完全重载
全局幂等；服务端创建没有幂等令牌，文档已明确限制。读操作均保留代际检查，
外发范围在后端重验，页面不提供执行模型的按钮。
