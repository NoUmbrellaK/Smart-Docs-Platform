# M3 任务工作区与显式执行

`/app.html` 登录并选择项目后显示 Agent tasks。复用同源会话及
[本人任务接口](m3-agent-tasks.md)，不向浏览器提供API密钥、MCP context或模型出口。
页面支持任务创建、查看及显式请求执行；执行服务须单独部署，不是已上线的自动执行服务，不代表M3验收完成。

## 用户流程

1. 在文件详情逐一点击 **Add current version to Agent task**。只有当前、非删除、
   文件策略允许且具体版本已批准时显示按钮；最多100个文件，每个固定一个版本。
   页面显示名称及精确file_id/version_id。后端创建时仍重新校验，页面选择不是授权依据。
2. 输入最多4000 UTF-8字节的问题，检查选中范围，再勾选外发确认。修改问题、增加/移除
   版本都会清掉勾选。确认涉及用户问题与选中资料，仅应使用公开/人工构造样例；
   这不是归档移动许可，也不自动替管理员批准版本。
3. 点击 **Create pending task**，只创建pending记录，不调用模型。查看该任务后，
   审阅固定范围及配置修订，重新勾选可能产生费用的执行确认，再 **Start this task**。
   页面只向单独部署的[受控同源执行入口](m3-agent-http.md)发送任务ID和空JSON，
   不直接调用模型或接受浏览器自定预算。可信服务端CLI仍可使用。
4. **Refresh tasks** 从最新一页读取，**Next task page** 用固定游标翻页，每页20条。
   **View task / Refresh task** 重新检查状态；未开始、执行中、完成、失败、中断、取消
   分别展示，不使用假进度百分比。没有定时轮询、自动恢复或后台浏览器重试。
5. pending/running/interrupted及waiting_confirmation/waiting_execution可点击 **Cancel task**。取消后重新查询权威状态；
   取消回执不明确则清掉旧操作按钮，提示刷新核对，不能宣称已取消。
6. completed/failed读取[运行结果接口](m3-read-agent.md)。回答作为纯文本草稿显示，
   不是M4交接报告；没有引用时明确提示。可见模型许可次数与脱敏失败码，不将次数
   等同供应商实际请求/计费。
   schema10的archive_operation单独展示最小持久归档回执，明确不是模型回答/交接报告，
   也不承诺文件仍在归档目标。等待确认/等待执行分别说明没有移动文件。
7. 点击引用先重验整个回答依赖，再鉴权读取精确file/version/chunk。显示行范围或
   PDF物理页和固定版本原文链接；不跳到新版、不把回答或原文当HTML执行。
8. **Load / refresh tool calls** 按需读取[服务端后端请求轨迹](m3-tool-audit.md)，最多64条，
   每条用原生details/summary展开工具名称、请求ID、UTC开始时间、后端耗时和脱敏参数。
   读工具只显示mode/query_bytes或selector；写工具仅显示条数及修订号，不渲染任意参数对象、原查询或正文；文本不作为HTML。
   unknown明确表示结果未确认；缺失耗时不是0ms，空记录不证明完成或没有模型调用。
   行数不等于MCP/模型调用次数，耗时不包含模型生成，本面板没有token用量或费用。
   同任务手动刷新先清旧行，以最新请求结果为准，不轮询、不启动工具或模型。
9. **View archive plan** 展示[具体归档修订](m3-archive-execution.md#网页确认与恢复)。编辑者/管理员
   审阅文件、固定版本、源/目标目录和理由后，勾选确认框再 **Confirm this revision**，或直接
   **Reject this revision**。确认不移动文件；随后 **Execute confirmed revision** 是另一次明确操作。
   响应不明确时使用 **Check archive receipt** 只读核对，不自动重试写入。

## 执行中、未知结果与恢复

只有pending任务显示启动确认；绑定归档策略的任务仅editor/admin显示，后端仍重新
检查权限及全部批准。每次查看任务都重新勾选，不把创建同意或归档确认当作执行按钮点击。
执行不自动确认归档方案、移动文件或继续等待中的任务。

请求在途时保留独立执行锁，切换项目、注销或刷新详情不会提前释放；刷新及取消仍可用。
网关响应不直接渲染回答，也不用于判断业务成功；请求结束后重新向C++读取状态和受保护结果。
视图已改变时忽略迟到的成功/错误，不能覆盖取消结果或其他项目内容。
若在旧执行请求期间查看另一pending任务，该视图保留禁止启动提示；请求结束后先刷新再操作。

浏览器请求最多等待300秒，超时/断网/错误提示结果可能未知，**不自动重试POST**。
使用 **Refresh task** 查询真实状态、结果/回执。刷新整页也只读取任务列表，不触发模型。
关闭页面、超时或断开连接不等于服务端取消或免计费；放弃任务须显式取消并核对状态。
多标签页及完全重载不共享浏览器锁，服务端原子领取仍为最终约束。

## 重复创建与页面失效

创建接口非幂等。浏览器对在途创建保留独立锁；文件刷新、策略变更、项目切换及注销
都不会释放尚未返回的创建请求。返回时如果原视图已经失效，不展示旧项目任务信息，
而提示此前创建结果可能不明确；必须核对本人任务并显式 **New draft (not a retry)**
后重新选择范围、输入问题和确认。创建失败也采用这一保守处理，不根据网络错误自动重放。
新草稿按钮不是旧请求重试，不复用旧问题或默认勾选。服务端并未增加幂等令牌；
多标签页、浏览器完全重载、用户主动再次创建仍可能产生独立任务，不能宣传为全局去重。

项目切换/注销清除问题、选中范围、列表、回答、来源、归档方案及调用摘要；文件列表刷新、上传完成、
文件变更、外发策略/本人角色变化也清除旧快照，迟到响应和旧按钮不能回填。
未监听其他客户端的所有变更；跨客户端变更在下一次服务端读取时检查，不能撤回
用户已经看见或已发送到供应商的数据。列表元数据仍可读，但回答、来源或调用摘要
读取失败后清掉详情/来源/摘要及旧按钮，要求重新核对任务，不保留旧敏感快照。

## 部署与验证

新增静态模块`/js/agent.js`已加入C++精确白名单。部署需同时更新静态资源和二进制，
当前开发分支要求[schema16](m3-tool-audit.md#schema16和部署)；没有迁移业务库或安装执行服务。
执行按钮需要同源代理精确转发execute路由；只有静态页面而没有该服务时不能执行。
沿用原生JS和手机单列布局，按钮至少44px，无新依赖或外部脚本。
[证据](../evidence/m3/task-ui/README.md)区分替身DOM行为测试、真实浏览器业务接口与
脚本化回答夹具；不把夹具结果当作真实DeepSeek质量或完整Agent闭环。
调用摘要验证见[轨迹网页证据](../evidence/m3/audit-ui/README.md)，归档确认验证见
[确认网页证据](../evidence/m3/archive-ui/README.md)。确认网页复用schema10及现有二进制；
没有新增迁移或生产部署。
显式执行的单元、真实浏览器/执行器及丢失响应恢复验证见[执行网页证据](../evidence/m3/execute-ui/README.md)。
